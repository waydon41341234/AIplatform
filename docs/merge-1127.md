## 取色器切 Key 范围（11-28）

### 行为

1. 打开行内取色器：在模块颜色页签点某一行的彩虹色块。
   - 电脑：取色器以浮层出现在该行左侧。
   - 手机：取色器以底部弹层出现。
2. 取色器标题保持行名（如「指示器（选中）」），右侧显示当前 Key。点标题旁的 ▾ 打开 Key 菜单。
3. 切到共享 Key（如主色 primary）后：
   - 该行的 Key 标签换成「跟随 primary」（`G6/FollowTag`）。
   - 取色器提示改为「主色在本页用于 12 处，应用时会问你改哪里」。
4. 判断是否弹窗：
   - 切 Key 后又改了色值，点「应用」时弹「应用到哪里？」（电脑居中弹窗，手机底部弹层）。
   - 只切 Key、没改色值，直接应用，不弹窗。
   - 没切 Key 时照旧只改这一行（v67 行为不变）。
5. 弹窗里的两个选项：
   - **只改这一行**（默认选中）：
     - 该行变成「自定义」状态，色值为新颜色，Key 标签显示「自定义」；
     - 主色不变，画布上只有这一处变色；
     - Toast「只改了这一行 · 撤销」。
   - **全部 12 处**：
     - 改写主色 primary，页面上用到主色的地方一起变；
     - 该行跟随 primary；
     - Toast「主色已更新，12 处已同步 · 撤销」（沿用 ColorToast）。
6. 选中项样式为淡蓝底 + 蓝字，不打勾，和全站规则一致。

代码：`js/editor.js`「取色器」一节（`pickerHtml` / `pickKey` / `pkApply` / `keyUses` / 「应用到哪里？」`ksBody`、`ksApply`）、`js/modpanels.js` `swRow`（FollowTag）、`css/editor.css`「取色器切 Key 范围」、文案 `js/i18n-editor.js` `ed/keyscope/*`（四种语言照 Figma 变量，写死的「主色 / primary / 12 / #10B26C」换成占位符）。

1. 模块颜色页签任一行点彩虹色块 → 行内取色器：电脑浮在该行左侧（顶边对齐该行，面板滚动跟着走）；手机底部弹层（画布不压暗），关掉后回到模块弹层。标题 = 行名 + ▾，右侧灰字 = 这一行现在的 Key；提示 `hint-row`。范围：Banner / 公告栏 / 帐户栏 / 游戏菜单 / 游戏卡片 / 底部导航的元素颜色行，顶部栏的底板、侧边栏入口行（公告选中文字、68 Key 改单独颜色、首页背景的取色器不变）。

3. 切到别的 Key → 「当前」= 那个 Key 的颜色，画布这一行先跟它；行的 Key 标签换成 FollowTag「跟随 <key>」，第一个色块 = 实时颜色带选中圈；提示 `hint-shared`「<Key> 在本页用于 N 处，应用时会问你改哪里」。切回这一行自己的 Key = 没切。
4. 应用：切了 Key 又改了色值 → 「应用到哪里？」（电脑居中弹窗 380 宽；手机底部弹层，盖在取色器上，「应用」在上「取消」在下）；默认「只改这一行」。只切 Key 没改色 → 直接跟随（Toast「已修改 · 撤销」）。没切 Key → v67 照旧。取消 / Esc / 点遮罩 → 回到取色器。
5. 只改这一行 → 这一行存自定义色值（Key 标签「自定义」），Key 不变；Toast `toast-row`「只改了这一行 · 撤销」。全部 N 处 → 改写这个 Key 的基础色，这一行跟随；Toast「<Key>已更新，N 处已同步 · 撤销」（= 141:1294 带 Key 名和处数，越南语 Key 名小写照 Figma）。两种都进撤销栈，Toast 撤销、顶栏撤销 / 重做都可以。
6. 「N 处」实时算：本页可见模块里绑定这个 Key 的颜色行（含引用 Key / 68 Key 改绑间接跟它的，不算正在改的这一行）+ 画布上直接用这个 Key 的元素（样式表 `var(--o-<Key>)` 规则在当前画布匹配到、可见，且把 `--o-<Key>` 换成探针色后颜色确实跟着变的；被颜色行 / 文字样式覆盖的不算）。经典蓝白默认页：主色 = 5 处（帐户栏登录描边 / 注册底、入口兜底图标、游戏菜单选中底 3 行 + 游戏卡片选中页签「热门」、「展开」2 处）。
7. 数据：跟随存 `'key:<名>'`，另记 `E.D.ecf[行]`（顶部栏 `tb:<行>`）= 取色器 Key 菜单切过去的；点色块、自定义色、恢复默认颜色都会清掉。
8. 和 Figma 的差别：取色器开着但还没切 Key 时，行内仍按 v67 显示（彩虹带圈、Key 标签「自定义」），Figma 第 1 步画的是第一个色块带圈 + 原 Key；行名用 HTML 现有文案（如「指示器 · 当前」，Figma 是旧名「指示器（选中）」）；N 是实际算出来的数（Figma 写 12）；Toast 沿用原型统一的顶部 Toast 位置。
