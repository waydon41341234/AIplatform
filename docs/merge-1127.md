## 取色器切 Key 范围（11-28）

### 行为

1. 打开行内取色器：在模块颜色页签点某一行的彩虹色块。
   - 电脑：取色器以浮层出现在该行左侧。
   - 手机：取色器以底部弹层出现。
2. 取色器标题保持行名（如「指示器（选中）」），右侧显示当前 Key。点标题旁的 ▾ 打开 Key 菜单。
3. 切到共享 Key（如主色 primary）后：
   - 该行的 Key 标签换成「跟随 primary」（`G6/FollowTag`）。
   - 取色器提示改为「主色在本页用于 12 处，应用时会问你改哪里」。
4. 判断是否弹窗：
   - 切 Key 后又改了色值，点「应用」时弹「应用到哪里？」（电脑居中弹窗，手机底部弹层）。
   - 只切 Key、没改色值，直接应用，不弹窗。
   - 没切 Key 时照旧只改这一行（v67 行为不变）。
5. 弹窗里的两个选项：
   - **只改这一行**（默认选中）：
     - 该行变成「自定义」状态，色值为新颜色，Key 标签显示「自定义」；
     - 主色不变，画布上只有这一处变色；
     - Toast「只改了这一行 · 撤销」。
   - **全部 12 处**：
     - 改写主色 primary，页面上用到主色的地方一起变；
     - 该行跟随 primary；
     - Toast「主色已更新，12 处已同步 · 撤销」（沿用 ColorToast）。
6. 选中项样式为淡蓝底 + 蓝字，不打勾，和全站规则一致。

### 行为

1. 在画布上点某张游戏卡片（例：炸金花），卡片出现选中框并弹出换图菜单。
   - 电脑：菜单是卡片右侧的浮层。
   - 手机：菜单是底部弹层。
2. 菜单头部显示游戏缩略图、名称、卡片样式和尺寸（如「经典 · 180×180」），下面三项：
   - **上传图片**（PNG / JPG · 按卡片尺寸裁切）：选好图后打开 v67 的「调整尺寸」弹窗，裁切框按卡片比例（经典 1:1）。点「采用」后卡片换图，Toast「图片已应用 · 撤销换图」。
   - **AI 生成图片**（4 张候选 · ✦10）：打开统一 AI 面板，标题「AI 生成 · 游戏图片」，范围「只这一张 · 炸金花」，提示词预填，规格「4 张 · 180×180」，不显示图标款式行。选一张后点「使用」，卡片换图，Toast 同上。
   - **恢复原图**：没换过图时是灰色（「还没换过图」）；换过以后可点（「换回游戏原来的图片」），点后 Toast「已恢复原图 · 撤销换图」。
3. 只换这一张卡片的图片，名称、角标、维护状态不变。
4. 「撤销换图」回到换图前的样子。
