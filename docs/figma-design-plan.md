状态：2026-11-22 进行中。设计稿：[业主定制设计平台 · 设计稿](https://www.figma.com/design/KEDg6ZjNHLCa2RmMn1veKH/%E4%B8%9A%E4%B8%BB%E5%AE%9A%E5%88%B6%E8%AE%BE%E8%AE%A1%E5%B9%B3%E5%8F%B0-%C2%B7-%E8%AE%BE%E8%AE%A1%E7%A8%BF?node-id=15-2)（新建文件，未改动任何已有原稿）。进度见 `PROGRESS.md`。

## 搭建顺序（用户规定，必须按序）

1. **变量**：配色和字号先建成 Figma 变量，所有图层只引用变量，不写死色值或字号。
   - 业主主题集合：11 个基础色变量 + 57 个规则变量（引用用变量别名；透明度派生、条件规则按色值规范第 5 节处理），名称与 68 个 Key 完全一致。
   - 平台界面集合：深色界面令牌（背景、层级、线、文字三级、蓝紫强调、成功/警告/错误）。
   - 字号集合：平台界面字号档位 + 业主页面组件字号档位。
2. **切图母组件**：凡是要用图片的位置（Logo、Banner 三规格、导航图标 @2x 逻辑尺寸、卡片五规格、背景图、平台 Logo），先做成按规范尺寸的切图母组件，组件内放可替换图片层。
3. **组件**：用变量和切图母组件搭建界面组件与业主页面九模块组件（含状态变体：登录/未登录、选中/未选中、已读/未读）。
4. **页面排版**：最后用组件实例拼画面，再连原型。

## 原型交互

- 项目列表「新建定制项目」→ 向导 ①→②→③ →「创建并开始设计」→ 编辑器
- 编辑器：点画布区域 → 右栏切到该模块；页签 内容/布局/颜色 切换
- 布局卡片点选 → 画布预览 →「采用布局」
- 素材槽「上传」→ 尺寸弹窗 →「采用这个结果」→ 回到编辑器（已填充）
- 素材槽「AI 生成」→ 创作框 →「生成」→ 候选 →「采用这一张」
- 预览状态 未登录/已登录、打开侧边栏 切换画面变体
- 顶栏「检查」→ 检查弹窗 → 点问题 → 定位到模块；「导出」→ 导出弹窗
