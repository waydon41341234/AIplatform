## 2. 原型（HTML）还没做 / 已知小问题

- **ED-20（P2，未做）**：画布里游戏菜单、底部导航点某一项时不会切换预览的选中项（现在第一项永远是选中态）。建议：模块已选中时再点某项 → 切换预览选中项（不进撤销记录），状态放在 `E.preview.gmActive / bnActive`。
- **手机模块面板没有遮罩**：点面板外的画布不会关闭面板；手机「68 个颜色用途」面板里的 × 会把所有面板一起关掉（应只关当前层）。
- **68 个颜色用途的用途说明**只有简体中文，没翻译成 繁 / 英 / 越。
- **演示数据没接 i18n**：业主项目名、模板名、游戏名、会话标题等 mock 数据在英文 / 越南语界面里仍显示中文。
- **通用 action 名没有前缀**：`window.ACT` 是全局共享的，今晚已经出现过一次重名（`tplUse`）。新增动作请按页面加前缀（`ed*` / `wb*` / `pg*` / `pc*`）。
- **工作台底部创作框的模型 / 配色 / 规格下拉改成往上弹**（框在屏幕底部，往下弹会出屏）。这是「下拉往下弹」总则之外的第二个例外（第一个是侧栏底部会话菜单），需要确认是否接受。
- **余额可能变负**：只在发起生成前校验余额、成功后才扣；同时发起多个生成时都能通过校验。正常流程碰不到，正式后端要做预扣 / 冻结。
- **手机工作台顶栏没有余额按钮**：沿用现有设计，手机在工作台看不到余额，要回首页或「我的」。
- **线上 Artifact 版本**里系统选图（上传 / 换图 / 参考图）可能被浏览器沙盒拦掉；要测上传请用单文件版 `定制平台原型-双击打开.html`。
- 所有 AI 生成、上传进度、支付、导出、Figma 授权都是**模拟**；失败状态用 `?fail=gen,load,save,export` 或提示词含「失败 / fail」触发，`?reset=1` 清空本地数据。

## 4. 正式产品还需要的（不在原型范围）

按方案，原型确认后需要转成正式实现：

1. **前端正式工程**：React + TypeScript，按 Figma 变量生成 tokens，组件化（现在原型是 vanilla JS 全量重渲染，只作交互参考）。图标用 `@phosphor-icons/react`。i18n 用正式库（插值替换原型的 `{n}` 写法）。
2. **后端 Node 服务**：账户 / 登录、项目与版本存储、模板库、素材库、点数余额与流水、通知、导出任务队列（见 `docs/api.md`、`docs/architecture.md`）。
3. **AI 网关**：可替换的模型接口（GPT Image、Gemini 等），生成任务排队、取消、失败退款（见 `docs/ai-gateway.md`）。业主 AI 网关由开发运维同事接入。
4. **支付**：现在充值是模拟流程，正式需接真实支付与对账。
5. **Figma 导出**：真实的 Figma OAuth 授权与写入；ZIP / 切图导出的真实打包。
6. **H5 / PC 真实预览**：用导出的 Key 和资源生成可访问的预览链接。
7. **Codex 适配**：正式代码要配好 `AGENTS.md`、目录说明和测试命令，方便其他部门用 Codex 维护。
8. 仓库以后可能迁到私有 GitLab。
