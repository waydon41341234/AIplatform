### 0.2 新功能：AI 首页设计（Waydon 2026-11-26 提出，规格草案）

**一句话**：业主上传效果图或选一个风格，再定主色，AI 结合默认提示词生成**完整首页设计**；页面模块不变，AI 只决定风格和颜色及配套素材。

**核心原则**：AI 不直接画一张整页图，而是输出「设计参数 + 素材」，套进现有九个模块渲染。这样结果可编辑、可撤销、可照常导出切图 / Key。

**入口**
- 首页创作框新增页签「首页设计」（和 中部导航 / 底部导航 / 游戏分类 并列）。
- 编辑器整页设置里加「AI 一键设计」按钮（作用于当前项目）。

**输入（二选一，可同时）**
- 上传效果图 / 参考截图（复用参考图格 RefSlot：类型、10 MB 限制、上传中、出错、可取消）。
- 选页面风格卡（首批 7 张）：**白金**（高级，浅底 + 香槟金）、**黑金**（高级，深底 + 金色）、科技蓝、清新明亮、节日红金、霓虹电竞、极简灰。白金 / 黑金为 Waydon 指定的高级风格，放在最前。
- 选图标风格（和页面风格分开选，默认跟随页面风格推荐）：面性填充、线性描边、双色、3D 质感、金属质感（配白金 / 黑金）、渐变、扁平插画。选的图标风格会写进图标样板和后续整套图标的提示词，三类图标（中部 / 底部 / 游戏分类）统一画风。
- 品牌主色：色板选一个 / 自定义 / 「从效果图取色」（上传后默认）。

**提示词**：默认提示词模板 + 风格描述 + 主色 + 效果图分析结果，系统拼装，业主不可见（高级模式可看）。模板放网关配置，不写死在前端。

**AI 输出（每套）**
1. 配色：11 个基础色 → 68 个颜色用途按现有推算规则生成（业主自己锁定过的 Key 不覆盖，规则同 ED-14）。
2. 模块样式：圆角档位、游戏菜单形状（胶囊 / 方块）、卡片角标风格、彩金池布局、页脚对齐等现有面板里已有的选项。
3. Banner：按当前规格 3 张（H5 尺寸 + PC 1920×564）。
4. 图标样板：中部导航 / 底部导航 / 游戏分类 各 1 个，按选定的图标风格出图。

**流程（闭环）**
1. 输入 → 发送：显示消耗与余额（costConfirm），余额不足走去充值并保留输入。
2. 生成中：进度 + 可取消（取消只扣已完成部分 / 不扣点，与工作台一致）。
3. 结果：**默认 3 套**整页预览（Waydon 已定；缩略 H5 + PC 切换），可放大看、可「再来一组」。
4. 选中一套 → 新建项目（首页入口）或应用到当前项目（编辑器入口，可撤销一步回到原样）→ 进编辑器。**进编辑器后每个模块都能单独修改**（Waydon 已定）：用现有的模块面板（内容 / 布局 / 颜色）改，AI 生成的配色、样式、Banner、图标都是普通可编辑数据；模块工具条可加「AI 重新生成这个模块」（沿用同一风格与颜色，只重出该模块的素材 / 样式，可撤销）。
5. 进编辑器后提示「生成整套图标」：中部 40、底部 35、游戏分类 13，沿用工作台「样板满意 → 生成其余」的扣点流程；也可跳过，先用默认图标。
6. 失败：整组失败 / 部分失败（某套缺图）都有状态，失败部分不扣点并写流水，可重试。

**技术**
- 取色：前端本地对效果图做主色聚类（k-means）即可；风格判断交给网关的视觉模型（返回结构化 JSON：风格标签、建议圆角、明暗）。
- 网关接口建议：`POST /ai/home-design`（入参：图片 id / 风格 key / 主色 / 数量；出参：N 套 {palette11, styles, bannerJobs, iconSampleJobs}），Banner 与图标走现有图片生成任务。
- 原型阶段全部模拟，`?fail=gen` 可测失败。

**交付顺序**：Figma（切图：页面风格卡缩略、图标风格示例；组件：StyleCard、IconStyleCard、DesignResultCard；页面：首页页签、输入、生成中、结果、应用后、失败，日夜 × 电脑 / 手机）→ HTML 原型（js/home.js 页签 + 新文件 js/aidesign.js）→ 测试（4 宽 × 日夜 × 四语 + 随机点击）。

**待 Waydon 确认**：风格卡清单（已定加白金、黑金；图标风格可选）、单次消耗点数、编辑器入口要不要。

## 2. 原型（HTML）还没做 / 已知小问题

- **ED-20（P2，未做）**：画布里游戏菜单、底部导航点某一项时不会切换预览的选中项（现在第一项永远是选中态）。建议：模块已选中时再点某项 → 切换预览选中项（不进撤销记录），状态放在 `E.preview.gmActive / bnActive`。
- **手机模块面板没有遮罩**：点面板外的画布不会关闭面板；手机「68 个颜色用途」面板里的 × 会把所有面板一起关掉（应只关当前层）。
- **68 个颜色用途的用途说明**只有简体中文，没翻译成 繁 / 英 / 越。
- **演示数据没接 i18n**：业主项目名、模板名、游戏名、会话标题等 mock 数据在英文 / 越南语界面里仍显示中文。
- **通用 action 名没有前缀**：`window.ACT` 是全局共享的，今晚已经出现过一次重名（`tplUse`）。新增动作请按页面加前缀（`ed*` / `wb*` / `pg*` / `pc*`）。
- **PC Banner 资源规格**：Waydon 已定 1920×564（通栏）。原型 PC 画布已按此显示；还没做的是 PC 专用 Banner 素材的上传 / 尺寸检查 / AI 生成（现在 PC 和 H5 共用同一组轮播图），以及 Figma PC 画面同步。
- **余额可能变负**：只在发起生成前校验余额、成功后才扣；同时发起多个生成时都能通过校验。正常流程碰不到，正式后端要做预扣 / 冻结。
- **手机工作台顶栏没有余额按钮**：沿用现有设计，手机在工作台看不到余额，要回首页或「我的」。
- **线上 Artifact 版本**里系统选图（上传 / 换图 / 参考图）可能被浏览器沙盒拦掉；要测上传请用单文件版 `定制平台原型-双击打开.html`。
- 所有 AI 生成、上传进度、支付、导出、Figma 授权都是**模拟**；失败状态用 `?fail=gen,load,save,export` 或提示词含「失败 / fail」触发，`?reset=1` 清空本地数据。
