# 后续阶段

按方案第 10 节的顺序。每项完成后更新 README“首版已完成”表。

## 1. Figma 源文件验证样板（方案要求最先做）

至少两个页面、可编辑文本、可换图片、矢量图标、自动布局/组件、主题变量、字号。导入 → 重开 → 修改 → 保存 .fig → 恢复核对。通过前不宣称 Figma 交付。
建议：写一个 Figma 插件读取 `project.json` + `theme.json`，按 `render/svg.ts` 相同的布局生成原生节点；68 Key 生成 Variables 与别名。

## 2. 其余页面类别

登录注册、下载引导条、APP 下载弹窗、游戏二级页、我的页面、优惠中心、推广。做法：
1. `HomePage` 抽象为通用 `Page { category, modules, flowOrder, height, preview }`，`project.pages` 改为按类别存（SCHEMA_VERSION 2 + 迁移）。
2. 每个类别在 `shared/catalog/` 登记模块、元素、状态、布局。
3. 渲染器按类别拆分文件；`IMPLEMENTED_CATEGORIES` 加入后左栏自动可点。
4. 共用组件（页脚、彩金池、导航）保持同一份定义，修改时显示影响页面。

## 3. PC 端

1920 宽画布、内容 1200，仅首页、彩金池、页脚、菜单栏。

## 4. 编辑能力补齐

字号档位、自定义指示器（选中/未选中两态）、游戏类型图标上传、装饰层自由定位、模块复制、版本快照与恢复、长文案/多语言预览。

## 5. 上线前（交给开发/运维）

账号登录（接公司现有体系）、按业主隔离项目和素材、数据库与对象存储、真实 AI 网关、充值与账本、任务队列、私有 GitLab CI、部署与域名。
