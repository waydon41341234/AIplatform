# 多语言规范（i18n）

平台界面支持四种语言。Figma 稿里所有界面文案都绑定在变量集合 **06 文案 i18n** 上，切换集合模式即可预览各语言；代码里用同名 key 读取。

## 语言与模式

| Figma 模式 | 代码 locale | 界面字体（Figma 预览） | 代码字体栈 |
| --- | --- | --- | --- |
| zh-Hans 简体中文（默认） | `zh-Hans` | Noto Sans SC | `"Microsoft YaHei", "PingFang SC", "Noto Sans SC", sans-serif` |
| zh-Hant 繁體中文 | `zh-Hant` | Noto Sans TC | `"Microsoft JhengHei", "PingFang TC", "Noto Sans TC", sans-serif` |
| en English | `en` | Inter | `Inter, "Segoe UI", system-ui, sans-serif` |
| vi Tiếng Việt | `vi` | Be Vietnam Pro | `"Be Vietnam Pro", "Segoe UI", system-ui, sans-serif` |

- 中文默认字体为微软雅黑（用户 2026-11-22 指定）。Figma 环境没有雅黑，稿内用 Noto Sans 预览；装好雅黑后改 `font/family` 变量的中文模式值即可全局替换。
- 字体由 `font/family` 变量按语言切换，文本样式（Platform/*）的字族都绑定该变量，不要在图层上写死字体。

## Key 命名

- Figma 变量名用 `/` 分组，代码 key 用 `.`：`nav/home` ⇄ `t('nav.home')`。变量的 WEB code syntax 已写成 `t('…')`。
- 分组：`nav` 导航 · `topbar` · `home` 首页标题 · `composer` 输入框 · `quick` 快捷入口 · `section` 区块标题 · `level` 定制等级 · `filter` 筛选 · `template` 模板卡 · `status` / `time` 状态与时间 · `common` 通用。
- 新增文案：先在 Figma 06 集合里加变量并填齐四种语言，再在代码语言包里加同名 key。缺译时回退到简体中文。
- 用户内容（项目名、模板名以外的业主数据）不翻译。数字类（如点数余额 `1,280`）只放数字，单位用图标表达。

## 排版规则（防溢出）

英文比中文长约 30–60%，越南语更长且有叠加声调符号。已用手机 375 宽在英文、越南语下检查首页。

1. **不给文字容器写死宽度**：按钮、标签、Chip 一律 hug 内容；卡片内文字 fill 宽度并自动换行。
2. **标题和说明可换行**，最多 3 行；卡片标题 1 行省略（`text-overflow: ellipsis`），完整文字放 `title` 属性。
3. **行高留足**：越南语声调会顶到上一行，行高不低于字号 × 1.4（规范里 body 14/22、title 20/28 已满足）。
4. **横向排列允许换行**：输入框工具栏、筛选 Chip 在窄屏换行或横向滚动，不要压缩文字。
5. **按钮文案控制在 2–3 个词**：如 Start customizing / Bắt đầu tùy chỉnh。
6. 新画面出稿时，至少切 en 和 vi 两个模式截一次图检查。
