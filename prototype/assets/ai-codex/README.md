## 导出方法

**图标**
1. 对 4 个分组画板调用 `get_screenshot`，参数为 1x、`contentsOnly=true`，得到透明底。不加这个参数会带上父画板底色。
2. 按组件框减去分组原点，裁出 78×78。
3. 做边缘 alpha 检查：图标不能碰到裁切边，也不能混进相邻图标。651 个全部通过。
4. LANCZOS 缩到 64×64，存为 webp q72、alpha_quality 50、method 6。

Figma 截图最高只有 1x，所以 78 到 64 是缩小。

**Banner 和缩略图**：Banner 存为 webp q60，宽 690；缩略图存为 webp q55，宽 240。为了满足 ≤1.9 MB 的预算，质量比 75/65 略低，放大检查过，边缘没有毛边或光晕。

## 与 AI_TPL / aidesign.js 的对应

| AI_CODEX | AI_TPL / aidesign.js | 说明 |
|---|---|---|
| `id` `style` `n` `dark` `th` | 同名 | 21 个 id 与 AI_TPL 一一相同 |
| `ec` | `AI_TPL.ec` / `E.D.ec` | 写法相同，由 modpanels.js `resolveKey` 解析。`category_active_text` 写成元素颜色 `gamemenu.activeText`。aidesign.js `autoEc` 写的 `bottomnav.active` 会盖住 `key:btmnav_active`，合并时应去掉或改成 `'key:btmnav_active'` |
| `layout` | `AI_TPL.m` 的子集 | 同名字段：banner_size、banner_corner、gm_style、gc_cols、gc_gap、gc_corner、bn_style。`bn_h` 是新增字段（底导高度 px）。m 的其余字段（banner_ind、gm_shape、jp_*、footer_align、sd_style、tb_mode、icon_style）Codex 没有，可用 `Object.assign({}, AI_TPL_BY[id].m, C.layout)` 补齐 |
| `a`（嵌套） | `tplAssets()`（扁平） | 用 `AI_CODEX_FLAT(C)` 转换后，可直接交给 `putTplAssets` / `tplSlides`。acct-*、bn-*[-off]、gm-N 已有消费方 |
| `a.notice` | 无 | putTplAssets 还没有消费方。喇叭对应 `m.notice.items[0].img`，信封对应 `items[1].img` / `imgOn` |
| `a.thumb` | `assets/ai-tpl/<id>/thumb.webp` | Figma 整页对照图，作用相同 |
| （无 logo） | `AI_TPL.logo` | Codex 首页用默认经典蓝顶栏的 logo，所以没有导出 |
| `name` | `ai-template/name-<id>` | 套名同时内嵌在数据里，也注册进 I18N |

**结构差异**
- 每套只有 1 张 Banner，FLAT 把它重复成 banner-1..3。
- 首页结构 21 套相同：
  - 模块顺序为 banner → notice → midnav → gamemenu（左侧栏）→ gamecards（3 列）
  - 顶栏为经典蓝
  - 底导是平的，没有凸起的中间按钮
  - 没有 jackpot、footer、sidebar
- 有些数值超出编辑器现有选项：
  - `bn_h` 的 104、124 不在 editor.js `BNAV_PX`（98/110/120/140）里，会按 h/2 显示；面板分段只有 98、120、140
  - `gc_corner` 的 8、18、24 和 `gc_gap` 的 12、16 也不在面板选项里

## 已知问题（Figma 原稿本身）

- g7「足球」在 fresh-1、fresh-2、neon-1、neon-2、neon-3 里画成了美式橄榄球。
- minimal-2 的 `bn-promo`（选中态）是浅灰，和未选中态几乎一样。
- 未选中态 `bn-*-off` 都是半透明灰；fresh-1 例外，是绿色。
- Figma `ad/gen/applied-blackgold-1` 的越南语是「Đen vàng · Điện tử」，与名称变量「Vàng đen · Slots」不一致。
- 原型 i18n-ad.js 的 `ad/st-fresh` 是「清新明亮」，而 Figma 的 `ad/st-fresh` 和 `ai-template/style-fresh` 是「巴西绿」。

## 重建

1. 替换 `<id>/` 下的 webp，或修改 `manifest.json`。改动后 `bytes` 和 `sizes` 要同步更新。
2. 运行 `python3 prototype/build-ai-codex.py`。脚本会校验 id 顺序和 714 个路径是否存在，然后重写 `js/ai-codex.js`。
3. `build-single.py` 会把 `assets/` 下所有 webp 递归内嵌进单文件。本目录 base64 后约 2.48 MB，其中缩略图约 0.44 MB；如果卡片是实时渲染的，缩略图可以加进 `SKIP`。
