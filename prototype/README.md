# HTML 交互原型（prototype/）

把 Figma 已有页面（首页、工作台、编辑器内页；电脑 + 手机；日 / 夜；四种语言）搭成可点击的 HTML，用来验证交互。
**这是原型，不是正式前端代码**：正式平台用 React + TS（见仓库根目录 `AGENTS.md`）。原型里的数据都是假的，生成、上传、导出都是模拟。

## 打开方式

纯静态文件，不用安装依赖。任选一种：

```bash
cd prototype && python3 -m http.server 8765
# 浏览器打开 http://localhost:8765/
```

不想开命令行：运行 `python3 prototype/build-single.py` 生成 `prototype/dist/prototype-single.html`（CSS、JS、图片全部内嵌的单文件），双击就能打开，也可以直接发给别人。注意别在压缩包里直接双击 `index.html`，要先解压，否则会是空白页。

地址参数：`?theme=dark|light&lang=zh-Hans|zh-Hant|en|vi`，例如 `index.html?theme=light&lang=vi#/editor`。
电脑宽度下右下角有一条半透明的「原型切换条」（日夜 + 四种语言），不属于平台界面。

## 页面（hash 路由）

| 路由 | 页面 |
| --- | --- |
| `#/home` | 首页（Hero + 创作框、定制等级、最近项目、模板） |
| `#/workbench` | 工作台（历史会话 + 生成记录 + 底部创作框） |
| `#/workbench/new` | 工作台新对话（空状态） |
| `#/editor` | 编辑器内页（先显示加载步骤，约 2 秒） |
| `#/custom` | 自定义模版：起始线框 → 灰阶线框排版 → 选风格 → 扣点 → 生成中 → 结果 → 采用进编辑器（首页「通用版式」区与模板页顶部的「自定义模版」卡进入） |
| `#/todo/<页面>` | 尚未设计的页面（模板、我的项目、历史生成、我的）→ 统一空状态 |

断点与 `docs/responsive.md` 一致：<600 手机、600–839 平板竖、840–1199 平板横 / 小屏、≥1200 电脑。编辑器 <840 用手机布局。

## 可验证的交互

- **外壳**：侧栏收起 / 展开（工作台默认展开并显示历史会话）、语言菜单、日夜切换、顶栏搜索回车 →「功能开发中」提示。手机为顶栏 + 底部 Tab。
- **创作框**：图标类型页签、参考图上传 / 移除、模型 / 配色 / 规格下拉（手机为底部面板）、自定义配色、生成一个 / 一套；一套先弹确认（显示消耗与余额），确认后扣点并跳到工作台。
- **工作台**：会话搜索、新对话、会话「⋯」菜单（往上弹：重命名 / 置顶 / 下载全部 / 删除确认）、重命名回车保存 / Esc 取消、置顶图钉；生成中进度、样板确认 → 生成其余 → 完成；单个下载、ZIP 下载、用作参考、重新生成。手机：历史抽屉、会话菜单与删除为底部面板。
- **编辑器**：左栏模块拖拽排序、眼睛显隐、侧边栏左右；「添加模块」（电脑往下弹的两列菜单 / 手机底部面板，加到所选模块下方）；删除模块（浮动工具条或手机面板的「⋯」→ 删除，带撤销；顶部栏 / 底部导航 / 侧边栏是固定模块，只能隐藏）；彩金池、中部导航、游戏菜单与游戏卡片（两个模块共用一个面板）、页脚、侧边栏、底部导航都有「内容 / 布局 / 颜色」三个页签，改了画布立即变（菜单栏仍是待设计）；画布点选模块 → 浮动工具条（上移 / 下移 / 隐藏 /「⋯」复制 / 恢复默认 / 删除）；撤销 / 重做；整页配色、11 个基础色 + 取色器（色谱 / 色相 / HEX / 推荐色 / Key 菜单）；Banner 尺寸、轮播（3 秒自动、拖动、圆点）、换图上传进度、AI 生成（自动提示词 + 关键词 + 4 个候选）；顶部栏内容 / 布局 / 颜色；登录态切换；H5 / PC（PC 为待设计空状态）；交付检查、导出（检查未通过拦截 → 导出中 → 文件列表）；手机端页面 / 模块 / 配色 / 预览四个面板与全屏预览。
- Esc 关闭任何弹层。

### 自定义模版

- **自定义模版（`#/custom`，2026-11-27）**：`js/customtpl.js`、`css/customtpl.css`、`js/i18n-custom.js`（`ct/*`），Figma 设计稿1127「11-27 自定义模版」01 线框组件 / 02 编辑器 / 03 AI 生成流程。

  - 点画布区块 → 蓝框 + 浮动工具条（上移 / 下移 / 复制 / 隐藏 / 删除 / 换布局，固定层只能换布局，悬浮层可隐藏）；右栏当前布局 + 参数；换布局面板列出该模块所有布局缩略图卡（选中淡蓝底蓝字，「已采用」= 打开前的布局），点卡片画布实时换；参数（列数 / 行数 / 圆角档 / 间距档 / 标题样式）实时生效，控件为 `CT.pseg()` 等宽分段，样式集中在 customtpl.css「参数分段控件」。撤销 / 重做；H5 / PC 的 PC 沿用 `window.PC_OPEN`，锁定时提示「暂未开放」。
  - 线框全部用 HTML/CSS 画（每个布局选项一个渲染函数，14 模块 43 个选项；只用底板色分层、图片为纯色块、不描边），日夜两套 `--wf-*` 变量。G4 左侧竖向分类栏会把紧跟其后的游戏分区放到右侧。

  - 结果选择：当前序列（顶部栏 + 可见内容区块 + 底部导航 + 悬浮层的布局选项）与 4 套起始线框比较，选项一致每个 1 分 + 顺序一致（最长公共子序列）每个 0.5 分，最高者胜；平分按所选风格（墨绿金 A / 香槟金 B / 暗夜绿 C / 清爽蓝 D）。百分比 = 得分 ÷（1.5 × 较长序列长度）。成品图 `assets/custom-tpl/result-A~D.jpg`。配色版本整页图 `result-X-风格.jpg` + Banner 切片 `banner-X-风格.jpg`（12 套 = 4 版式 × 3 非原稿风格，Figma 页 65895:2「04 配色版本」用「配色 · 色相层」HUE 叠层导出，750 宽 1×；第三方品牌图标保留原色；11-28 补齐 B/C/D 到 A 的完整度）。从 D 起始不改 → 方案 D 100%；空白起始 → 平分，按风格。
  - 采用 → 新建项目「自定义模版 · 方案X」并进现有编辑器（主题色按方案：A / C 绿、B 金、D 蓝），加载完提示「已采用 AI 生成结果」，提示上的「返回线框」回到 `#/custom`（排版保存在 LocalStorage `proto.ct`）。右栏「上次生成」可再打开上次结果。
  - 手机（<840）：顶部返回 / 撤销 / 重做 / 生成；底部工具栏 模块库 / 图层 / 换布局（未选中时为页面排版与全局样式）/ 预览；模块库、图层、换布局、选风格、生成进度都是底部抽屉；图层用把手拖动排序。

### 取色器切 Key 范围（11-28）

Figma「04-11-28 取色器 · 切 Key 范围」65966:104739（电脑 / 手机 × 夜 / 日 7 步 + 英 / 越第 4 步），组件 G6/ScopeOption、G6/FollowTag、G6/KeyScopeDialog；文案 `ed/keyscope/*`（`js/i18n-editor.js`）。代码在 `js/editor.js`「取色器」一节和 `js/modpanels.js` 的 `swRow`。

- **打开**：模块「颜色」页签任一行（Banner、公告栏、帐户栏、游戏菜单、游戏卡片、底部导航的元素颜色行，顶部栏的底板 / 侧边栏入口行）点彩虹色块 → 行内取色器。标题 = 行名（每次渲染按当前语言取，中途切语言也跟着换），右侧灰字 = 这一行现在的 Key（自定义色写「自定义」，游戏菜单按钮底没选颜色写「按钮图」，投影这类写死的默认色写色值）；提示「画布已实时预览，应用后只改这一行」。
  - 刚打开、还没改色：这一行照常显示（第一个色块 / 当前 Key 带圈，Key 标签 = 现在的 Key，Figma 第 1 / 2 步），画布不变（投影 15% 透明、按钮图都保持原样）；「当前」= 这一行现在的颜色（带透明度的照原样）。色值一改，这一行才显示成「自定义」（彩虹带圈），画布实时预览。
  - 电脑：浮在右栏左侧，顶边对齐该行，面板滚动时跟着走。画布内容（手机 + 竖排模块工具条）往左让出位置：画布够宽（约 1400 以上）手机、工具条都不被盖；不够宽就尽量让，并保证正在改的元素（画布上用这一行颜色的元素）露出来，盖到就把取色器移到它下面 / 上面。
  - 手机（<840）：底部弹层，画布不压暗，取消 / 应用后回到模块弹层。取色中跨过 840（转屏 / 拉窗口）在浮层和底部弹层之间切换，取色器和还没应用的预览都留着。
- **Key 菜单**：标题旁 ▾ 往下展开 11 个基础色（当前 Key 淡蓝底蓝字）。切到别的 Key → 「当前」换成那个 Key 的颜色，画布这一行先跟它；行的 Key 标签换成「跟随 <key>」（淡蓝底蓝字胶囊），第一个色块显示该 Key 颜色并带选中圈；提示「<Key> 在本页用于 N 处，应用时会问你改哪里」。切回这一行自己的 Key = 没切。
- **N 处**（实时从画布量，不写死，不算正在改的这一行）：把 CSS 变量临时换成探针色，看可见元素的颜色变没变（只改字色的要真的落到字 / 图标上，没有边框的边框色不算，被颜色行 / 文字样式盖掉的不算）。
  - 颜色行：绑定这个 Key（含通过引用 Key / 68 Key 改绑间接跟它的）、而且画布上正在显示的模块颜色行、顶部栏底板 / 侧边栏入口、帐户栏入口角标、余额框颜色，每行 1 处（游戏菜单按钮底显示按钮图、没有兜底图标、没登录看不到的都不算）。
  - 文字样式里选了这个 Key 色块、画布上有这段文字的，每项 1 处。
  - 画布上直接用这个 Key 的元素（样式表或行内样式写 `var(--o-<Key>)`，含公告内容里选中文字的颜色），每个元素 1 处。经典蓝白默认页：主色 = 2 处（登录 / 注册、「展开」；11-28 起游戏卡片上方不再有「热门 / 最近 / 收藏」页签，菜单在中部时另加「选中文字 / 下划线」1 处），辅助绿 = 1 处（公告「中级场」）。
  - 0 处、1 处有各自的句子：0 处提示「<Key>在本页没有其它地方用到」，弹窗第二项写「改写<Key>」；英文 1 处用单数（1 place）。
- **应用**：切了 Key 又改了色值 → 「应用到哪里？」（电脑居中弹窗 / 手机底部弹层，盖在取色器上）：「只改这一行」（默认选中）/「全部 N 处」，选中项淡蓝底蓝字、不打勾；取消或 Esc 回到取色器；弹窗开着时 Ctrl+Z / ↑↓ 等快捷键不在背后改页面。只切 Key 没改色 → 直接跟随，提示「已修改 · 撤销」。没切 Key → 只改这一行（v67），Toast「只改了这一行 · 撤销」。
  - 只改这一行：这一行存自定义色值（彩虹带色、Key 标签「自定义」），Key 不变，画布只有这一处变；Toast「只改了这一行 · 撤销」。
  - 全部 N 处：改写这个 Key 的基础色（页面上用到它的地方一起变），这一行跟随它；Toast「主色已更新，N 处已同步 · 撤销」（Key 名按所选 Key）。
  - Toast 在画布上（电脑：手机画布底部导航上方居中；手机：模块弹层上方），同 Figma 5a / 5b。
  - 都进撤销栈：顶栏撤销 / 重做、Ctrl+Z / Ctrl+Shift+Z 都可以。Toast 的「撤销」只撤这一次应用：还是最后一步就正常撤销（可重做）；Toast 还在时又改了别的，就只把这次动过的几项（这一行、Key 的基础色、跟随标记）改回去、另记一步，后来的改动不动。
- **数据**：跟随 = `E.D.ec[行]` / `E.D.tb.colors[行]` 存 `'key:<名>'`，另在 `E.D.ecf[行]`（顶部栏行为 `tb:<行>`）记下是取色器 Key 菜单切过去的；点色块、自定义色、恢复默认颜色都会清掉这个标记。
- **测试用**：`EDX.keyUses('<Key>', true)` 列出这个 Key 在本页算进「N 处」的每一处。
